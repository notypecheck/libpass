# libpass

`libpass` is an alias for [passlib](https://pypi.org/project/passlib/): it
contains no code and simply installs the official
[passlib](https://github.com/notypecheck/passlib) package at the same version.

Use `pip install passlib` directly. If you have `libpass` pinned,
`pip install -U libpass` installs official `passlib` with no code changes —
the import name has always been `passlib`.

Source repository: https://github.com/notypecheck/passlib
